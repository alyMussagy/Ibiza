# Design system

Identidade: coral `#FF385C`, coral profundo `#C91C47`, carvão `#222222`, branco `#FFFFFF`, cinzas `#F7F7F7`, `#717171` e bordas `#DDDDDD`. O coral profundo é usado em texto pequeno e botões com letras brancas para melhor contraste. Coral vivo identifica a marca. Tokens Tailwind no CSS global; Inter local; Lucide; cartões arredondados; foco visível, skip-link, labels, redução de movimento e menu móvel.

Marca em `src/components/layout/brand.tsx`, agora com o logótipo oficial fornecido pelo proprietário: `public/brand/ibiza-oficial.png`. O ficheiro original permanece intacto; o CSS enquadra as margens brancas no cabeçalho/rodapé. Páginas base partilham layouts, pesquisa e cartões. Sem avaliações, preços, disponibilidade, parceiros ou datas de eventos inventados.
